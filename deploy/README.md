# Канбат на сервере в интернете — пошагово

Итог: Канбат работает круглосуточно по адресу `https://ваш-домен`, без вашего компьютера.
ИИ — **Qwen в Yandex AI Studio** (Qwen3.6 35B, рассуждения выключены), данные — на вашем сервере.

Понадобится ~30 минут и три покупки:

| Что          | Где                                              | Примерно              |
| ------------ | ------------------------------------------------ | --------------------- |
| Сервер (VPS) | Timeweb Cloud, Selectel, REG.RU — любой с Ubuntu | 200–450 ₽/мес         |
| Домен        | REG.RU, Timeweb, RU-CENTER                       | несколько сотен ₽/год |
| ИИ           | Yandex AI Studio (оплата по факту)               | ~1–2 ₽ за обращение   |

---

## Шаг 1. Сервер

1. Зарегистрируйтесь у провайдера (например, [Timeweb Cloud](https://timeweb.cloud/services/vds-vps)) и создайте облачный сервер:
   - **Ubuntu 24.04** (или 22.04);
   - **2 ГБ ОЗУ**, 1–2 процессора, 20+ ГБ диска (1 ГБ тоже заработает — скрипт добавит подкачку, но сборка будет дольше);
   - регион — Москва или Санкт-Петербург;
   - доступ — **по паролю root** (проще) или по SSH-ключу.
2. Запишите **IP-адрес** сервера и **пароль root** (придут на почту или видны в панели).

## Шаг 2. Домен

1. Купите домен (например, `kanbat.ru`) у регистратора.
2. В настройках домена → **DNS** добавьте запись:
   - тип **A**, имя **@** (сам домен), значение — **IP сервера**.
3. Изменения расходятся от 15 минут до нескольких часов. Проверить: в PowerShell `nslookup kanbat.ru` — должен показать IP сервера.

## Шаг 3. Ключ ИИ (Yandex AI Studio)

1. Откройте [console.yandex.cloud](https://console.yandex.cloud) и войдите с Яндекс ID.
2. Создайте **платёжный аккаунт** (карта РФ). Если предложат стартовый грант — отлично.
3. Откройте каталог **default** и скопируйте его **идентификатор** — строка вида `b1g…` (видна рядом с названием каталога).
4. Откройте [aistudio.yandex.ru](https://aistudio.yandex.ru) в этом же каталоге → **«Создать API-ключ»** (правый верхний угол) → **«Создать»**.
5. Скопируйте **секретный ключ** — он показывается один раз. Никому его не пересылайте.

## Шаг 4. Установка (из Windows)

1. Откройте **PowerShell** в папке, где лежит `kanbat.zip`, и загрузите архив на сервер:

   ```powershell
   scp .\kanbat.zip root@IP-СЕРВЕРА:/root/
   ```

   На вопрос «Are you sure…» ответьте `yes`, затем введите пароль root (при вводе не отображается).

2. Зайдите на сервер:

   ```powershell
   ssh root@IP-СЕРВЕРА
   ```

3. На сервере выполните (можно скопировать все строки сразу):

   ```bash
   apt-get update && apt-get install -y unzip
   unzip -o kanbat.zip && cd kanbat
   bash deploy/install.sh
   ```

4. Скрипт спросит:
   - **домен** — `kanbat.ru` (без `https://`);
   - **идентификатор каталога** — `b1g…` из шага 3;
   - **API-ключ** — секретная часть из шага 3 (при вставке не отображается — это нормально);
   - **код специалиста** — можно оставить предложенный;
   - **код администратора организации** — открывает настройки помощника (роль, тон, правила); можно оставить предложенный, дайте его только администратору.

   Дальше всё сам: Docker, сборка (3–8 минут), HTTPS, проверка ИИ, ежедневные копии данных.
   В конце — адрес сайта, код специалиста и код администратора.

## Шаг 5. Проверка

1. Откройте `https://ваш-домен` — экран входа Канбата.
2. Создайте кабинет, напишите обращение — помощник должен ответить за несколько секунд.
3. «Настройки» → **«Проверить скорость ИИ»**.
4. Войдите как специалист (с кодом из шага 4) в другом браузере — откроется пульт. С кодом администратора в меню появится «Организация»: выберите шаблон отрасли и настройте помощника.

## Обслуживание

Все команды — на сервере (`ssh root@IP-СЕРВЕРА`), в папке `cd /root/kanbat`.

| Задача                    | Команда                                                                                         |
| ------------------------- | ----------------------------------------------------------------------------------------------- |
| Обновить Канбат           | в PowerShell `scp .\kanbat.zip root@IP:/root/`, на сервере `bash /root/kanbat/deploy/update.sh` |
| Проверить ИИ              | `docker compose exec kanbat node scripts/check-ai.mjs`                                          |
| Журнал                    | `docker compose logs -f kanbat` (выход — Ctrl+C)                                                |
| Перезапустить             | `docker compose restart`                                                                        |
| Копия данных сейчас       | `bash deploy/backup.sh` (ежедневные — в `/root/kanbat-backups`, 14 дней)                        |
| Поменять ключ, домен, код | `bash deploy/install.sh --reconfigure`                                                          |

Восстановить данные из копии:

```bash
cd /root/kanbat && docker compose stop kanbat
tar -xzf /root/kanbat-backups/kanbat-ДАТА.tar.gz -C /root/kanbat
docker compose start kanbat
```

## Если что-то не так

| Что видно                                       | Что сделать                                                                                                                                                             |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Сайт не открывается / «небезопасное соединение» | Домен ещё не указывает на сервер. `nslookup домен` должен показать IP сервера. Подождите; сертификат Caddy получит сам. Журнал: `docker compose logs caddy \| tail -30` |
| «ИИ сейчас недоступен»                          | `docker compose exec kanbat node scripts/check-ai.mjs` — скажет, что не так: ключ (401), каталог (403), модель (404), баланс (402)                                      |
| Сборка упала на загрузке образов                | Docker Hub из России открывается не всегда. Скрипт уже прописал зеркала в `/etc/docker/daemon.json`; повторите `bash deploy/install.sh`                                 |
| Сборка упала на `npm ci`                        | Нет доступа к registry.npmjs.org: в `.env` добавьте `NPM_REGISTRY=https://registry.npmmirror.com/` и повторите                                                          |
| Нужно больше места/памяти                       | Увеличьте тариф VPS в панели провайдера — данные сохранятся                                                                                                             |

## Как это устроено

```
Браузер ──HTTPS──▶ Caddy (сертификат Let's Encrypt) ──▶ Канбат (Node.js: сайт + API)
                                                        ├── data/kanbat.json — кабинеты, обращения, БатФорум
                                                        └── Qwen в Yandex AI Studio (OpenAI-совместимый API)
```

- Всё в двух контейнерах (`docker-compose.yml`), перезапуск при сбое и после перезагрузки сервера.
- Настройки — в `/root/kanbat/.env` (виден только root), данные — в `/root/kanbat/data`.
- Своя модель вместо облака (закрытый контур): сервис `ollama` в `docker-compose.yml` и `LLM_PROVIDER=ollama` —
  нужен сервер с видеокартой, иначе ответы по 1–3 минуты.
